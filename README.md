# 메인트 니니닝!

프로필 사진, 자기소개, 트윗 성향, 드림 성향, NG, 좋아하는 캐릭터를 한 장의 메인트 이미지로 정리하는 사이트. 만든 메인트는 PNG로 저장하거나 클립보드에 바로 복사할 수 있어요.

## 기능

- **프로필**: 프로필 사진(확대 · 위치 조절), 닉네임, 아이디, 계정 요약 (아이디 · 요약은 보이기 / 숨기기)
- **소개**
  - 자기소개 · NG: 자유롭게 쓰는 글 칸
  - 트윗 성향: RT · 마음 · 일상 · 탐라대화 · 인용 · 구독 · 썰 · 연성 · 앓이 · 기타를 눌러서 고르고, 직접 추가 · 지우기. 고르지 않은 태그를 흐리게 같이 보여 줄 수도 있음
  - 드림 성향: ONLY · OPEN · CBC + 비고
- **좋아하는 캐릭터**: 이미지 1 ~ 6개, 장르 · 캐릭터 이름 · 커미션 출처
  - 개수와 들어갈 칸 모양에 맞춰 그리드가 자동 배치 (3개면 큰 칸 + 작은 칸 둘, 5개면 큰 칸 + 작은 칸 넷 …)
  - 이름표: 이미지 위 · 이미지 아래 · 숨김
  - 커미션 출처는 이미지 오른쪽 아래에 작게 들어감
  - 사진 확대(1 ~ 4×) · 위치(가로 · 세로) 조절, 여러 장 한 번에 넣기, 순서 바꾸기
- **구성**
  - 판형: 16:9 · 16:10 · 3:2(기본) · 4:3 · 1:1 · 4:5 · 9:16 · 직접 입력. 긴 변 1600px 기준
  - 메뉴: 보이기 / 숨기기, 이름 바꾸기, 순서 바꾸기, 너비(넓게 · 반), 글 메뉴 · 태그 메뉴 추가
  - 갤러리: 위치(자동 · 왼쪽 · 오른쪽 · 아래), 크기, 제목
- **서식**: 글 칸에서 굵게 · 기울임 · 형광펜 (도구 또는 Ctrl/⌘ + B · I · Shift + H). 글에는 `**굵게**` · `*기울임*` · `==형광펜==`으로 저장됨
- **텍스트**: 제목 · 본문 글꼴 따로, 글자 크기, 줄 간격, 자간, 정렬, 메뉴 제목 모양(기본 · 포인트 · 굵게), 단어 단위 줄바꿈, 자동 맞춤(글이 넘치면 크기를 줄여 카드 안에 맞춤)
- **스킨**: 화이트 · 클라우드 · 다크 · macOS(배경화면 4종, 창 라이트 / 다크) · 그리드(라이트 · 다크 · 블루) · 패턴(무늬 8종, 바탕 · 무늬 색, 크기) · 사진 배경(덮개 농도), 포인트 색, 모서리 둥글기
- **편집**
  - 되돌리기 · 다시 하기 (Ctrl/⌘ + Z · Ctrl/⌘ + Shift + Z)
  - 이미지: 고르기 · 끌어다 놓기 · `Ctrl/⌘ + V` 붙여넣기
  - 미리보기에서 칸을 누르면 그 설정 탭으로
  - 미리보기에서 사진을 끌면 위치, 휠을 굴리면 확대가 바뀜
  - 빈 칸 안내 글은 미리보기에만 보이고 저장 이미지에는 들어가지 않음
- **저장**: PNG 1× · 2× · 3×, 클립보드 복사, 모바일은 공유 시트
  - 파일 이름: `[메인트닝]닉네임_날짜.png`
- **자동 저장**: 이 브라우저(IndexedDB)에만 저장 · 서버로 보내지 않음. ‘작업 파일로 내보내기 / 불러오기’로 다른 기기에 옮기기
- **반응형**: 데스크톱은 왼쪽 메뉴 + 설정 패널, 휴대폰은 아래 탭 + 시트 (저장 이미지는 항상 원래 배치)

## 배포 (GitHub Pages)

빌드 과정 없는 정적 사이트예요.

1. 이 폴더의 파일을 저장소 루트에 올리기
2. 저장소 **Settings → Pages → Build and deployment**에서 `Deploy from a branch`, 브랜치 `main` / 폴더 `/ (root)` 선택
3. 잠시 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 열림
